# Vakra Interiors Website

A modern and responsive interior design website built using HTML, CSS, and JavaScript.

## Features

- Responsive Design
- Modern Navigation Bar
- Smooth Scrolling
- Product Showcase Section
- Interior Services Section
- Contact Form Integration (Formspree)
- WhatsApp Floating Button
- Instagram Floating Button
- Mobile Friendly Layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Remix Icons
- Formspree

## Project Sections

- Home
- About
- Products
- Services
- Contact
